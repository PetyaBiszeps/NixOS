# NixOS Configuration

Personal modular NixOS configuration built around flakes, Home Manager, Niri, Noctalia, NVF, development tools, gaming support, and AMD graphics.

This repository is designed to bootstrap a fresh NixOS installation into a complete daily-driver system.

## Overview

The configuration is split into small focused modules:

```text
.
├── flake.nix
├── install.sh
├── mount.sh
├── hosts/
│   └── nixos/
│       ├── default.nix
│       ├── variables.nix
│       ├── variables.local.nix   # generated/local
│       ├── hardware.nix          # generated/local
│       └── disks.nix             # optional/generated/local
├── profiles/
│   └── amd.nix
├── modules/
│   ├── core/
│   ├── drivers/
│   └── home/
└── wallpapers/
```

When enabled, it installs tools for:

## Host Variables

Most host-specific options live in:

```text
hosts/nixos/variables.nix
```

Private/local values are stored in:

```text
hosts/nixos/variables.local.nix
```

`variables.local.nix` is generated by `install.sh` and should not be committed.

Important variables:

```nix
timeZone = "Europe/Kyiv";
defaultLocale = "en_US.UTF-8";
keyboardLayout = "us,ru,ua";

enableNFS = false;
printEnable = true;
devSupportEnable = true;
gamingSupportEnable = true;

displayManager = "ly";
defaultSession = "niri";
desktopShell = "noctalia";
defaultShell = "zsh";

IDE = "zeditor";
browser = "brave";
terminal = "ghostty";
fileManager = "nautilus";
```

## Installation Guide

### 1. Install Base NixOS

Download the official NixOS ISO and install a minimal system.

Recommended base:

- No desktop environment
- Flakes can be enabled later by this configuration
- Boot into the installed CLI system

### 2. Prepare Temporary Tools

From the fresh system TTY:

```bash
mkdir -p ~/Documents/Web
cd ~/Documents/Web

nix-shell -p git openssh gh openssl
```

### 3. Clone the Repository

```bash
git clone https://github.com/PetyaBiszeps/NixOS.git
cd NixOS
```

### 4. Run the Installer

```bash
chmod +x install.sh
./install.sh
```

The installer will:

1. validate the repository layout
2. collect local user information
3. optionally create a new user
4. generate `hosts/nixos/variables.local.nix`
5. generate `hosts/nixos/hardware.nix`
6. optionally generate an SSH key
7. optionally authenticate GitHub through `gh`
8. optionally switch the Git remote from HTTPS to SSH
9. run `nix flake check`
10. optionally run `nixos-rebuild switch`

For a specific host:

```bash
HOST=nixos ./install.sh
```

## Rebuild Commands

After editing the configuration, rebuild with:

```bash
sudo nixos-rebuild switch --flake "path:.#nixos" --no-write-lock-file
```

The Zsh module also provides helper aliases.

### `nixos-build`

Runs:

```bash
sudo nixos-rebuild switch --flake "path:.#nixos" --no-write-lock-file
```

### `nixos-update`

Updates `flake.lock` and rebuilds:

```bash
nix flake update
sudo nixos-rebuild switch --flake "path:.#nixos" --no-write-lock-file
```

### `nixos-clean`

Removes old system generations and runs garbage collection:

```bash
sudo nix-env --profile /nix/var/nix/profiles/system --delete-generations old
sudo nix-collect-garbage -d
```

### `nixos-build-clean`

Rebuilds and then cleans old generations.

### `nixos-all`

Updates the flake, rebuilds, and cleans old generations.

## Disk Mount Helper

The repository includes `mount.sh`, an interactive helper for generating additional disk mounts.

```bash
chmod +x mount.sh
./mount.sh
```

It scans disks with UUIDs, asks which ones should be mounted, and writes:

```text
hosts/nixos/disks.nix
```

Generated mounts use:

```nix
options = [ "nofail" "x-systemd.automount" "x-systemd.idle-timeout=60" ];
```

For a specific host folder, the script currently uses `HOSTNAME`:

```bash
HOSTNAME=nixos ./mount.sh
```

## Local / Generated Files

These files are machine-specific and should stay local:

```text
hosts/*/hardware.nix
hosts/*/disks.nix
hosts/*/variables.local.nix
```

They are intentionally ignored by Git.

## SSH / GitHub

During installation, `install.sh` can optionally:

- generate an Ed25519 SSH key
- authenticate GitHub through `gh`
- add the SSH key to GitHub
- switch the repository remote from HTTPS to SSH

To verify GitHub SSH access manually:

```bash
ssh -T git@github.com
```
